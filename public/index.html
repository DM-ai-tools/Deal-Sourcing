How this works

  1. The system fills this table for you when a run finishes — you never add rows by hand.
  2. Once a broker replies, move the listing along with the Status dropdown on its row.
  3. Export CSV gives you the six columns exactly as specified, ready for a spreadsheet.

Searches

Define the buy-box once, then run it as often as you like.

Getting started

  1. Your buy-box is already saved below — 12 industries, SDE $750k–$1M, auctions excluded.
  2. Press Start dry run. It finds and records every match, prepares each message, and sends nothing.
  3. Check the Tracker, then read a prepared message under Settings to confirm the wording.
  4. When you are happy, arm sending in Settings and use Start live run.

Leave every state unticked for all locations. Preview URLs shows exactly which pages will be swept.

Runs

Each sweep, what it found, and what it sent.

Reading a run

  1. A run has two halves: it finds every matching listing, then contacts the new ones.
  2. Log shows live progress. Stop halts immediately — nothing half-sent.
  3. If a run is interrupted, start another; it picks up only the listings never contacted.

“0 listings found” almost always means the site blocked the connection, not that nothing matched. Check Settings → Test connection.

Settings

Contact details, the message, pacing, and how the system reaches the site.

Before your first live run

  1. Check the contact details and message below — these go on every form.
  2. Enter the BizBuySell login for the buyer account.
  3. Press Test connection. It must say Reachable, or runs will find nothing.
  4. Only then tick Arm sending. Until you do, every run is a dry run.

Start with a low daily cap — 20 or 30 — and long delays. Hundreds of identical messages in a short window is how an account gets suspended.

Google Sheet

In Google Cloud create a service account, download its JSON key, then share the sheet with that account email as an Editor. The sheet is a mirror: it is rewritten on every sync, so change statuses here in the dashboard, not in the sheet.

Inbox monitoring — how you find out a broker replied

Outlook and Exchange mailboxes cannot use a password here Microsoft turned off basic authentication for IMAP across Microsoft 365, so a correct password is still refused — this was tested against deals@hyperboards.com and returned AUTHENTICATE failed. Use Graph: in Entra, create an app registration, add the Application permission Mail.Read, grant admin consent, then paste the tenant ID, client ID and a client secret above.

Read-only, always: it opens the mailbox read-only, never deletes, never marks anything as read, and tracks its place by message number. A matched reply turns the listing green and copies what they said into the tracker and the sheet. Out-of-office replies and bounces are recorded but never counted as an answer.

If you are forwarding into a mailbox you also use for other things, set “Only read mail addressed to” to the address the brokers reply to — otherwise every message in that inbox is stored in the deal database and shown under Replies.

Daily scan

Leave “all states” unticked in the search: BizBuySell's national pages already cover every state in 12 requests, where selecting all fifty makes 600 — which the site refuses long before it finishes.

One scan per day across the whole buy-box. If sending is armed, that scan also messages everything new it finds, paced and capped. 14:00 UTC is mid-morning in the US, so enquiries land while brokers are at their desks. The once-a-day guard is checked against the database, not memory — a redeploy cannot cause a second scan.

Transport — how the system reaches BizBuySell

Automatic tries Chrome, then Camoufox, then Firecrawl, and sticks with whichever returns actual listings. A blocked request here comes back as a normal-looking page with no data in it, so each one is judged on whether listings arrived — not on the status code.

The mode tests prove the site can be read. “Test the send path” fills a real contact form and stops before the button — the only check that proves messages can actually go out. Nothing is sent.
